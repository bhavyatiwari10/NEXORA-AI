# 7-minute Nexora AI Demo

## 00:00 — Overview
Show KPI cards, AI signal banner, revenue chart and priority queue.

## 01:00 — Inbox
Open the extraction studio and paste:

`bhai 2 kg basmati chahiye, kal tak deliver ho jayega?`

Run the pipeline and explain intent, product, language, confidence and stage tracker.

## 02:00 — CRM + Orders
Open Customers and Orders. Explain that structured chat data can become CRM records and order records.

## 03:00 — Finance
Show invoice/payment views and the PDF invoice endpoint. Explain CGST/SGST vs IGST logic and simulated checkout.

## 04:00 — Follow-ups
Show automatically detected reminders and generated message drafts.

## 05:00 — Ask Nexora
Ask: `Which customers have pending payments over ₹5,000?`
Show the result and the safe query specification.

## 06:00 — Evaluation Lab
Explain technical, visual and user-centric metrics. Highlight the 50-case gold dataset and SUS/trust measures.

## 07:00 — Research contribution
Close with: Nexora evaluates not only whether the LLM extracted correctly, but whether the entire conversational analytics workflow helps a user complete a business task accurately, quickly and confidently.
