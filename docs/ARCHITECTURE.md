# Nexora AI Architecture

```mermaid
flowchart LR
A[WhatsApp / Instagram / Telegram / Mock Chat] --> B[Message Normalizer]
B --> C[LLM Provider]
C --> D[Extraction + Confidence + Source Spans]
D --> E[Pydantic Validation]
E --> F[Entity Resolution]
F --> G[(SQLite / PostgreSQL)]
G --> H[CRM + Orders]
H --> I[GST Invoice]
H --> J[Payment Simulation]
G --> K[Follow-up Scheduler]
G --> L[Analytics Query Builder]
L --> M[Safe Query Spec]
M --> N[Recharts Visuals]
G --> O[Evaluation Lab]
O --> P[Technical + Visual + User Metrics]
```

## Design principles

1. Offline-first demo mode.
2. Provider abstraction instead of vendor lock-in.
3. No raw SQL generated by the conversational analytics layer.
4. Every automated action is auditable.
5. Human review is available for low-confidence fields.
6. Research evaluation measures the complete user task, not only model output.
