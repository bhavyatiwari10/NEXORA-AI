# Nexora Presentation Notes

## Title
A Unified User-Centric Evaluation Framework for Large Language Models in Conversational Visual Analytics

## Contribution points
1. Unified conversation-to-CRM pipeline.
2. Per-field confidence and source-span explainability.
3. Human-in-the-loop validation for uncertain extraction.
4. Safe natural-language analytics through whitelisted query specs.
5. Technical + visual + user-centric evaluation framework.
6. Offline deterministic benchmark path for reproducibility.

## Demo script
1. Open Dashboard and show seeded KPIs.
2. Open Conversations and run the Hinglish order example.
3. Show extraction, validation and pipeline state.
4. Open Orders / Customers to show structured CRM output.
5. Ask Nexora: “show revenue over time” and inspect the query spec.
6. Open Evaluation and explain technical, visual and user-centric metrics.

## Metrics
Field precision/recall/F1, exact match, JSON validity, schema pass rate, hallucination rate, latency, token cost, robustness, chart correctness, query-spec accuracy, insight faithfulness, task completion, time-to-task, manual corrections and SUS.
